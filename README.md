# CryptoTracker

Приватний трекер криптопортфеля. Усі записи шифруються на пристрої, і жоден сервер не бачить їх у відкритому вигляді.

## Як влаштовано

- **Шифрування.** AES-256-GCM. Ключ даних випадковий, він захищений головним паролем (Argon2id, 64 МБ, 3 проходи) і окремо ключем відновлення (160 біт, HKDF-SHA256).
- **Зберігання.** IndexedDB браузера. Там лежить лише зашифрований блок і публічний кеш цін.
- **Ціни.** Публічний API CoinGecko: щоразу завантажуються топ-250 монет цілком, тож із запиту не видно, які монети у портфелі. Окремий запит робиться тільки для монет поза топ-250 і для пошуку, який ви запускаєте явно.
- **P&L.** Метод середньої ціни, як на CryptoRank (`js/calc.js`). Комісії не враховуються.
- **Ціна на дату транзакції.** За останні 365 днів береться з CoinGecko (погодинно), за старіші дати — з Binance (свічка 1 год, пара ТІКЕР/USDT). Такий запит показує сервісу монету й дату.
- **Захист коду.** Content-Security-Policy дозволяє з'єднання лише з api.coingecko.com, api.github.com (синхронізація) та api.binance.com (старі ціни), а картинки — лише з CDN CoinGecko. Залежностей із CDN немає: Argon2 (`hash-wasm` 4.12.0, MIT) лежить у `vendor/`.
  SHA-256 `vendor/argon2.umd.min.js`: `dcec617a2e1b700fa132d1583a186cb70611113395e869f2dd6cc82b415d3094`

## Синхронізація

Зашифроване сховище (`vault.json`) лежить у приватному репозиторії GitHub і передається через Contents API за fine-grained токеном. Цей токен має доступ лише до одного репозиторію (Contents: Read and write) і зберігається всередині зашифрованих даних. GitHub бачить тільки шифротекст.

- **Транзакції.** Об'єднуються за id, перемагає новіша правка. Видалення зберігаються як «надгробки».
- **Конфлікти.** Якщо два пристрої записали одночасно, GitHub відповідає 409. Тоді застосунок завантажує свіжу версію, об'єднує її зі своєю і пробує записати ще раз.
- **Пароль і ключ відновлення.** Новіша зміна з будь-якого пристрою переноситься на всі інші. Ключ даних при цьому не змінюється.
- **Історія.** Історія комітів репозиторію водночас слугує історією резервних копій.

Для локальних тестів є імітація GitHub API (`js/dev-mock-github.js`). Вона не публікується і вмикається тільки на localhost через `localStorage['ct-dev-mock-github']`.

## Резервні копії

Налаштування → «Завантажити копію». Файл зашифрований тим самим паролем, його можна зберігати будь-де. Без пароля або ключа відновлення відновити дані неможливо.

## Локальний запуск

```bash
python3 -m http.server 8765 --directory .
```

Потім відкрийте http://localhost:8765.

## Оновлення

Після зміни будь-якого файлу збільшіть `VERSION` у `sw.js`, щоб встановлений застосунок підхопив нову версію.
